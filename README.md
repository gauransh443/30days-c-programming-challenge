# 30 Days C Programming Challenge

## Introduction

This repository contains my solutions to the 30 Days C Programming Challenge. Each challenge includes the problem statement and my C program solution.

## Challenges

* **Challenge 03:** *
Problem Statement
A student is purchasing items from an online store. Read the purchase amount, customer type (1 = Student, 2 = Regular Customer),
and delivery distance in kilometres. Determine the discount and delivery charge using conditional statements. Display the purchase
amount, discount amount, amount after discount, delivery charge, and final payable amount.

* **Challenge 04:** *
Problem Statment
Create a C program called LOOPLAB to analyse daily expenses. Repeatedly read expense amounts until the user enters 0. For each positive
amount, classify it using the rules below, update counts and totals, and finally display a summary. Use loops, conditional statements, arithmetic
operators, and variables. Do not use arrays, functions, or strings.

* **Challenge 05** *
Problem Statement
Create a menu-driven C program that lets a user choose a mathematical operation. After each operation, display the menu again. The program 
must stop only when the user selects Exit

* **Challenge 06** *
Problem Statement
A smart-campus activity monitor records the number of visits over several time slots. Your task is to write a C program that studies the
sequence, finds meaningful patterns, and then rotates the data for a cyclic report. The important part is to plan the logic before coding
and to handle unusual cases correctly.

* **Challenge 07** *
Problem Statement
A campus event uses ticket IDs from 1 to N. The scanner records N entries, but one ticket ID is missing and another ticket ID has been scanned twice. Your job is to audit the scan log, identify the missing and duplicate IDs, and measure how far the scan sequence is out of order. Plan your logic before writing code.

* **Challenge 08** *
Problem Statement
Campus security has divided a high-traffic area into an N × N grid. Each cell stores a risk score from a sensor: 0 means no risk and 100 means the highest risk. You must build a C program called GRIDWATCH that traverses the grid in different ways to identify risky zones and recommend a response. This is not just a maximum-value problem: your solution must correctly analyse rows, columns, diagonals, boundaries, and neighbouring cells.

* **Challenge 09** *
Problem Statement
Your university is organising a technical event in an auditorium with 5 rows and 8 seats in each row. Develop a menu-driven C program called SEATSMART to manage seat reservations. The program must allow users to view seats, book or cancel an individual seat, reserve consecutive seats for a group, and view an occupancy report. You must use a two-dimensional array and separate user-defined functions for the major operations.
