# 30 Days C Programming Challenge

## Introduction

This repository contains my solutions to the 30 Days C Programming Challenge. Each challenge includes the problem statement and my C program solution.

## Challenges

* **Challenge 03:** *
Problem Statement
A student is purchasing items from an online store. Read the purchase amount, customer type (1 = Student, 2 = Regular Customer),
and delivery distance in kilometres. Determine the discount and delivery charge using conditional statements. Display the purchase
amount, discount amount, amount after discount, delivery charge, and final payable amount.

* **Challenge 04:** *
Problem Statment
Create a C program called LOOPLAB to analyse daily expenses. Repeatedly read expense amounts until the user enters 0. For each positive
amount, classify it using the rules below, update counts and totals, and finally display a summary. Use loops, conditional statements, arithmetic
operators, and variables. Do not use arrays, functions, or strings.

* **Challenge 05** *
Problem Statement
Create a menu-driven C program that lets a user choose a mathematical operation. After each operation, display the menu again. The program 
must stop only when the user selects Exit

## Language
